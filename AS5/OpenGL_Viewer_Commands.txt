1. OpenGL Viewer 交互说明
----------------------------------------------------------------

  键盘：
    r / R    以当前相机位置执行光线追踪，保存 -output 指定的 TGA
    t / T    在鼠标位置追踪单像素射线，可视化 Ray Tree
    g / G    切换体素网格可视化模式
    q / Q    退出程序

  鼠标：
    左键拖拽    绕场景中心旋转相机
    中键拖拽    平移（truck）
    右键拖拽    推拉（dolly）

  体素网格可视化模式（按 g 循环，需 -visualize_grid）：
    模式 0    绘制占用体素外露面 + 场景包围盒（按图元密度着色）
    模式 1    绘制 DDA 遍历到的体素面（按遍历顺序着色）
    模式 2    绘制射线进入网格时穿过的面（按遍历顺序着色）

  颜色渐变（白 → 绿 → 青 → 蓝 → 黄 → 橙 → 红）：
    模式 0    按单元格重叠图元数量着色（1 个 = 白，越多越红）
    模式 1/2  按 DDA 遍历顺序着色（第一个格 = 白，越往后越红）

  Ray Tree 线段颜色：
    灰色    主光线（primary ray）
    绿色    阴影光线（shadow ray）
    红色    反射光线（reflected ray）
    蓝色    折射光线（transmitted ray）

  调试相机：在 GL/glCanvas.C 的 display() 中取消注释 drawAxes()，
            显示 RGB 坐标轴。

  体素网格参数：
    -grid <nx> <ny> <nz>   在场景包围盒上划分均匀体素网格

  控制台 printOccupancy：. 空  # 1  2-9 数字  * 为 10+

  光线追踪参数：
    -shadows              启用 shadow rays
    -transparent_shadows  半透明阴影
    -bounces <N>          最大递归深度
    -weight <W>           权重截止阈值
    -shade_back           透明/双面场景必需

  OpenGL 预览参数：
    -tessellation <theta> <phi>   Sphere 多边形细分
    -gouraud                      Sphere Gouraud 插值
    -specular_fix                 光线追踪高光 spec *= N·L
    -normals <file.tga>           输出法线可视化图（|N| 映射为 RGB）
