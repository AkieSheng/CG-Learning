6.837 Assignment 4 — OpenGL Viewer 调试命令行
本文件列出 Assignment 4 样例场景及其 -gui / Ray Tree 调试命令。

----------------------------------------------------------------
0. 运行前准备（Windows PowerShell）
----------------------------------------------------------------

  # 首次：编译
  cd E:\Akie\Assignment\AS4
  mingw32-make

----------------------------------------------------------------
1. OpenGL Viewer 交互说明
----------------------------------------------------------------

  键盘：
    r / R    以当前相机位置执行光线追踪，保存 -output 指定的 TGA
    t / T    在鼠标位置追踪单像素射线，可视化 Ray Tree（调试用）
    q / Q    退出程序

  鼠标：
    左键拖拽    绕场景中心旋转相机
    中键拖拽    平移（truck）
    右键拖拽    推拉（dolly）

  Ray Tree 颜色：
    灰色    主光线（primary ray）
    绿色    阴影光线（shadow ray）
    红色    反射光线（reflected ray）
    蓝色    折射光线（transmitted ray）

  调试相机：在 GL/glCanvas.C 的 display() 中取消注释 drawAxes()，
            显示 RGB 坐标轴。

  光线追踪参数：
    -shadows              启用 shadow rays
    -transparent_shadows  半透明阴影（光路穿过透明体的距离衰减）
    -bounces <N>          最大递归深度（0 = 仅局部着色）
    -weight <W>           权重截止阈值（颜色向量模长）
    -shade_back           透明/双面场景必需

  OpenGL 预览参数：
    -tessellation <theta> <phi>   Sphere 多边形细分
    -gouraud                      Sphere Gouraud 插值
    -specular_fix                 光线追踪高光 spec *= N·L

----------------------------------------------------------------
2. 无 Mesh 场景（在 AS4 根目录运行）
----------------------------------------------------------------

  cd E:\Akie\Assignment\AS4

  # scene4_01  球体落在平面上的硬阴影
  .\raytracer -input InputFiles\scene4_01_sphere_shadow.txt -size 200 200 -output OutputFiles\gui4_01.tga -shadows -gui

  # scene4_02  彩色物体产生的彩色阴影
  .\raytracer -input InputFiles\scene4_02_colored_shadows.txt -size 200 200 -output OutputFiles\gui4_02.tga -shadows -gui -tessellation 50 25 -gouraud

  # scene4_04  反射球（对比不同 bounces，无 -gui）
  .\raytracer -input InputFiles\scene4_04_reflective_sphere.txt -size 200 200 -output OutputFiles\out4_04a.tga -shadows -bounces 0 -weight 0.01
  .\raytracer -input InputFiles\scene4_04_reflective_sphere.txt -size 200 200 -output OutputFiles\out4_04b.tga -shadows -bounces 1 -weight 0.01
  .\raytracer -input InputFiles\scene4_04_reflective_sphere.txt -size 200 200 -output OutputFiles\out4_04c.tga -shadows -bounces 2 -weight 0.01
  .\raytracer -input InputFiles\scene4_04_reflective_sphere.txt -size 200 200 -output OutputFiles\out4_04d.tga -shadows -bounces 3 -weight 0.01

  # scene4_04  GUI + Ray Tree
  .\raytracer -input InputFiles\scene4_04_reflective_sphere.txt -size 200 200 -output OutputFiles\gui4_04.tga -shadows -bounces 2 -weight 0.01 -gui

  调试 Ray Tree：启动 -gui 后，将鼠标移到阴影/反射边界附近，按 t 查看 ray tree。

5. 常见错误
----------------------------------------------------------------

  错误：Assertion failed file != NULL (scene_parser.C line 398)
  原因：含 TriangleMesh 的场景未在 Meshes/ 目录下运行
  修复：cd Meshes，使用 ..\raytracer -input ..\InputFiles\...

  错误：找不到路径 AS4\AS4
  原因：已在 AS4 内再次执行 cd AS4
  修复：确认当前目录（pwd），跳过 cd 或 cd 到正确路径

  错误：无法将 ./raytracer 项识别为 cmdlet
  原因：在 Meshes/ 下使用了 ./raytracer（exe 在上一级）
  修复：改用 ..\raytracer

  错误：Permission denied（mingw32-make 链接失败）
  原因：raytracer.exe 被 -gui 窗口占用
  修复：关闭 GUI 或 taskkill /F /IM raytracer.exe 后重新编译
